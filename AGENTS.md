# Project Instructions

## Plan maintenance

- Treat `README.md` as the living implementation plan. Update it when project decisions or implementation progress change the plan.
- After completing a planned step, mark it complete in the README or remove it if a completion checklist no longer adds value.
- Remove or revise steps that are no longer needed; keep remaining steps actionable and in the intended order.

## Shared guidance

If an `agents` folder is located next to this project folder, read its `AGENTS.md` file. Otherwise, use the [shared guidance online](https://github.com/Henahax/agents/blob/main/AGENTS.md). Resolve relative paths in the shared guidance from the `agents` folder. Load only task-relevant rules and skills; do not maintain a per-project skills list.
